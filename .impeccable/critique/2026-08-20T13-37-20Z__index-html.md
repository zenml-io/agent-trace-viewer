## Design Specificity Verdict

Authored in the content layer (paths, teaching errors, epistemic honesty, moment heuristics); visual layer competent but category-interchangeable except density strip + flow graph. Sharpest finding: PRODUCT.md says "comparison is the point" but the capture matrix computed by all three parsers is never rendered (the removed Replay-evidence table carried it; its content needs a better-designed home, not resurrection).

Detector: 2 findings — side-tab border-left (largely false positive: neutral token + functional kind colors, though 4px heavy) and zero-offset green glow on brand dot (genuine; greps found two more colored glows: primary button shadow, flash ring). Confirmed: focus-visible exists, aria-labels on symbol buttons, lang/title/meta present. Gaps: no prefers-reduced-motion; 8 sub-12px font sizes.

## Priority Issues

- [P0] Comparison story has no home. Capture matrix computed and discarded; researcher persona's core question unanswerable. Fix: comparison-native presentation (capability cards or compare surface with the three samples). Command: shape.
- [P0] No text search. Core Operate task unserved; Ctrl+F fails on collapsed payloads. Fix: search input filtering to ghost rows over eventText(). Command: polish.
- [P1] Keyboard/SR access broken on new features. Density ticks, flow nodes, moments, ghost rows are click-only spans/divs; fake radio pattern; no tab semantics; focus destroyed on re-render; jumps don't move focus. Fix: real buttons, tablist semantics, aria-live, focus after jump. Command: audit + polish.
- [P1] No feedback/ceiling on large traces. Sync parse freeze; unvirtualized timeline; schema() dumps entire event array into one pre. Fix: busy state, auto-collapse threshold, cap schema dump. Command: harden.
- [P2] Finish cluster: auto-detect source; --faint contrast ~4.0:1 at 11-12px; sub-12px type floor; add prefers-reduced-motion; neutralize glows. Command: polish + quieter.
